# Independência Linear

Um conjunto de vetores \( \{v_1, v_2, \dots, v_k\} \) é **linearmente independente** se a única combinação linear que produz o vetor nulo for a combinação trivial:

\[
a_1 v_1 + a_2 v_2 + \dots + a_k v_k = 0 \quad \Rightarrow \quad a_1 = a_2 = \dots = a_k = 0
\]

Caso contrário, o conjunto é linearmente dependente.
