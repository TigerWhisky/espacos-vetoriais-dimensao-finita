# Subespaços Vetoriais

Um subconjunto \( W \subseteq V \) é um **subespaço vetorial** se:

1. Contém o vetor nulo
2. É fechado para a adição
3. É fechado para a multiplicação por escalar

## Exemplos

- Núcleo de uma transformação linear
- Imagem de uma transformação linear
- Span de um conjunto de vetores
